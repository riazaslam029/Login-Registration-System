# Contributing

Thank you for helping improve Login & Registration System.

## Workflow

1. Fork the repository and create a focused branch.
2. Open `Project4.sln` and verify the project builds in Visual Studio 2022.
3. Keep changes focused and consistent with the existing beginner-friendly scope.
4. Test registration, duplicate-user handling, login, invalid credentials, and exit behavior.
5. Open a pull request with a concise summary and validation notes.

## Guidelines

- Keep user-facing messages clear and consistent.
- Do not commit `users.txt`, build output, Visual Studio caches, or credentials.
- Update the README when setup or behavior changes.
- Security improvements should explain their compatibility and migration impact.
- Be respectful and constructive in issues and pull requests.

## Reporting Bugs

Include the steps to reproduce the issue, expected behavior, actual behavior, Visual Studio/toolchain details, and any relevant console output.
